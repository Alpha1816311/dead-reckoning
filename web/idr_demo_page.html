What This Does

📡
Real-time GNSS + INS Fusion Combines phone GPS with accelerometer and gyroscope for smooth, continuous position tracking.
🔴
Live GNSS Blackout Test Press a button to gate out GNSS. Navigation switches to Dead Reckoning from live IMU.
♻️
Automatic GNSS Recovery Restoring GNSS triggers smooth Reacquisition blending back to GNSS_INS_FUSED mode.
🗺️
Live Map Track OpenStreetMap tiles with colour-coded track: blue = fused, orange = dead reckoning, yellow = reacquisition.
💾
Session Recording Every sensor reading, GNSS fix, and navigation output saved to an NDJSON file. One-tap export.
🔌
No Server Required The navigation engine runs entirely on the phone. No laptop, no USB, no Python server needed.

Navigation Modes

● GNSS + INS FUSED GPS fixes and IMU combined. Best position accuracy. Active when GNSS is available.
◆ DEAD RECKONING IMU only. Position integrated from gyro heading + accelerometer speed. Active during blackout.
↺ REACQUISITION GNSS restored. Smooth blending from DR position back to fused GPS position over ~5 fixes.
○ WAITING FOR FIX Sensors running but fewer than 2 GNSS fixes received. Normal at startup outdoors.

Install on Android

1 Download APK Tap the button below or scan the QR code from the presentation.
2 Allow unknown sources Settings → Apps → Special App Access → Install Unknown Apps → enable for browser/Files.
3 Install the APK Open the downloaded file and tap Install.
4 Grant permissions Allow Precise Location when prompted. No other permissions required.
5 Press START NAVIGATION Go outdoors. Wait for GNSS fix. Watch the mode switch to GNSS + INS FUSED.
6 Test Blackout Press ⚠ START BLACKOUT while moving. Watch the mode switch to DEAD RECKONING.
⬇ Download APK
Android 8.0+ (API 26) required. Tested on API 26–35.
No internet connection required for navigation. Internet used only for map tiles (optional).

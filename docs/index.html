How IDR Fusion works

1
Sensor ingestion

Accelerometer + Gyroscope at ~100 Hz from Android hardware sensors. Magnetometer for heading bootstrap.

2
GNSS fusion

GPS/Network provider at 2 Hz. Extended Kalman Filter tightly couples IMU pre-integration with GNSS position.

3
Dead-reckoning fallback

When GNSS signal is lost, the DR engine propagates position purely from IMU data — no fix required.

4
On-device only

All computation happens on the phone. No data leaves the device. Works in airplane mode.

Installation instructions

  1. Download the APK Tap the blue "Download APK" button above. Chrome may warn — tap Download anyway.
  2. Allow unknown sources Android → Settings → Apps → Special app access → Install unknown apps → Chrome → Allow.
  3. Install Open the downloaded IDR-Fusion-SIH-MVP.apk from your notifications or Downloads folder and tap Install.
  4. Grant permissions Allow Location (Fine) when prompted — required for GNSS. All sensors start automatically.
  5. Done The IDR Fusion Navigate screen opens immediately. Walk outside for GNSS fix, then go indoors to test DR.
